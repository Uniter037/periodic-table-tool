# 元素周期表绘图工具

将 13 个分散的"元素周期表绘图"脚本整合为一个带图形界面的工具，输出结果与
原始脚本**逐像素完全一致**，并在此基础上增加了自定义热力图、实时预览、
图形化标注、自定义颜色与预设等扩展功能。

## 功能一览（v1.1）

| 类别 | 说明 |
| ---- | ---- |
| 13 种绘图模式 | 与原脚本输出逐像素一致（见下方对照表） |
| 自定义热力图 | 自由设置色图、范围、小数位、标题 |
| **实时预览** | 画布实时显示输出图片效果，参数/数据/颜色/开关变化即时刷新（所见即所得） |
| **UI 布局设置** | 「视图」菜单可选布局：左右分栏 / 上下分栏 / 自动调整；**随窗口宽度自动切换**（窄窗口自动上下分栏），选择持久化保存，重启恢复 |
| **界面缩放（字号/控件）** | 「视图 → 界面缩放」手动调节 80%~150%，或选**自动**——字号与控件随窗口宽度自动缩放（0.8~1.5 倍） |
| **预览区域自适应** | 预览画布随窗口尺寸实时调整大小；「视图 → 预览区域大小」可手动调节预览区/数据区比例（40/50/60%） |
| **图形化标注** | 开启「图形化标注模式」后直接点击预览中的元素格即可标注数值/文本，与表格输入实时双向同步；Notebook 双 Tab 可切换输入方式 |
| **颜色条开关** | 可随时显示/隐藏颜色条 |
| **自定义颜色** | 可视化编辑任意数量颜色锚点（添加/移除/改色/恢复默认），实时生效 |
| **命名预设** | 将整套设置与数据保存为命名预设（JSON），可加载/删除，重启后仍可复用 |
| 数据输入 | 表格逐格编辑 / 文件导入 / 载入示例 / 图形化点击标注 |
| 输出自动改名 | 绝不覆盖已有文件 |

## 使用说明

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 元素周期表布局数据已内置（`core/elements_data.py`，源自 mendeleev 1.2.0），
> 运行时**无需安装 mendeleev**，启动和出图都是秒级。

### 2. 启动（图形界面）

```bash
python main.py
```

### 3. 操作步骤

1. **选择模式**：下拉框选择要生成的图表类型；
2. **输入数据**（四种方式任选）——
   - 在右侧 118 行表格中**双击"数值 / 标注"列**逐个编辑；
   - 勾选预览区上方**「图形化标注模式」**，直接**点击预览图中的元素格**输入数值/文本标注；
   - 点击 **"导入数据文件"**（每行一个元素 `Ag, 0.0101`、字典或 JSON）；
   - 点击 **"载入示例数据"**，一键填入该模式的原始示例数据；
3. **实时预览**：右侧画布即时反映所有设置与数据（即为输出图片的预览）；
4. **UI 布局**：「视图」菜单可选择 左右分栏 / 上下分栏 / **自动调整**（默认）——
   自动模式下窗口宽度低于约 1150px 自动切为上下分栏、宽窗口切回左右分栏；
   布局选择与窗口尺寸会自动保存，下次启动恢复；
5. **界面缩放**：「视图 → 界面缩放」选择 **自动**（字号与控件随窗口宽度缩放 0.8~1.5 倍）
   或手动 80% / 100% / 125% / 150%；「视图 → 预览区域大小」调节预览区占比（40/50/60%）；
6. **高级设置**：颜色条开关、自定义颜色（仅自定义模式）、命名预设（保存/加载/删除）；
7. **点击"生成图片"**：输出到 `output/` 目录，文件**自动改名**，**绝不覆盖**已有文件。

### 4. 数据文件格式（导入入口）

```
# 每行一个元素，符号与数值之间用空格 / 逗号 / 等号 / 冒号分隔
Ag, 0.0101
Au = 0.0111
Sc: 3c1          # 标注模式允许文本值
```

也支持字典文本 `{'Ag': 0.0101, 'Au': 0.0111}` 和 JSON `{"Ag": 0.0101}`。

### 与原脚本的兼容性说明

原脚本是为旧版 matplotlib 编写的，本工具在其输出一致的前提下做了两处最小兼容处理
（已在验证脚本中注明）：

- **图1（`Hui_Tu-1.py`）**：使用已被 matplotlib 3.11 移除的 `cm.get_cmap()`，
  且 `plt.colorbar()` 未关联 axes —— 验证时替换为新写法；
- **图2（`Hui_Tu-2.py`）**：原脚本存在 bug（`ha='left'` 与 `text_props` 中的
  `ha='center'` 重复导致 `TypeError`，无法运行）—— 按原意图实现；
- **图4（`Hui_Tu-4.py`）**：颜色映射列表含笔误 `'pectral'`（matplotlib 中不存在），
  运行会中断 —— 已修正为 `'Spectral'` 并自动跳过无效名称。

## 常见问题

- **提示缺少模块**：先执行 `pip install -r requirements.txt`；
- **预览不可用**：缺少 TkAgg 后端时预览区显示提示，其余功能与出图不受影响；
- **界面文字乱码**：请以 UTF-8 编码运行（Windows 下一般无此问题）。
