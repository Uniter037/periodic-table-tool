# 元素周期表绘图工具

一个图形化工具：把元素数据标注在元素周期表上

## 功能简介

- 🎨 **14 种绘图模式**：13 种经典样式（蓝白红、YlOrRd、Blues、YlGn、coolwarm、
  底部标注、高亮标注等，输出与原始脚本逐像素一致）+ 1 种完全自定义模式
- 👁 **实时预览**：右侧画布即时显示成图效果，改参数、改数据、换颜色，预览同步刷新
- 🖱 **图形化标注**：直接**点击预览图中的元素格子**即可输入数值 / 文本标注，
  与表格编辑实时双向同步
- 🎛 **自定义颜色**：可视化编辑任意数量的颜色锚点（添加 / 移除 / 改色 / 恢复默认）
- 📊 **颜色条开关**：随时显示 / 隐藏颜色条
- 💾 **命名预设**：把整套设置和数据保存为预设，一键加载 / 删除，重启后仍可复用
- 📐 **自适应界面**：布局（左右 / 上下 / 自动）、字号与控件缩放（自动 / 手动）、
  预览区域大小均可调节，随窗口自动适配
- 🔤 **自动改名保存**：每次生成自动使用新文件名（`periodic_table_时间戳.svg`），
  绝不覆盖已有文件

## 快速开始

### 1. 安装（需要 Python 3.9+）

```bash
pip install -r requirements.txt
```

> 元素周期表布局数据已内置，运行**无需安装 mendeleev** 等数据库，启动即用。

### 2. 启动

```bash
python main.py
```

Windows 下也可以直接**双击 `main.py`** 启动。

## 使用帮助

### 第 1 步：选择绘图模式

在左侧「绘图模式」下拉框中选择。热力图模式显示数值，标注模式显示文本标签
（两种模式的填数方式见下）。

### 第 2 步：输入数据（四种方式任选）

**方式 A：表格编辑** —— 在「① 表格编辑」页，找到元素行，**双击"数值 / 标注"列**，
直接输入：

- 热力图模式：输入数字，如 `0.0101`、`-26.56`；
- 标注模式：输入文本，如 `3c1`、`1b`；
- 输入框留空并回车 = 清除该元素。

**方式 B：图形化点击标注（推荐）**

1. 勾选预览区上方的 **「图形化标注模式」**；
2. 直接在预览图中**点击某个元素格子**；
3. 在下方「② 图形化标注」页输入数值 / 文本，点 **「应用标注」**；
4. 再次点击同一元素可修改；输入框留空点「应用」= 清除该元素。

表格与图形化标注**实时双向同步**，怎么方便怎么来。

**方式 C：导入数据文件** —— 点「导入数据文件」，选择 txt / csv / json。
格式见下文「数据文件格式」。

**方式 D：载入示例数据** —— 点「载入示例数据」，一键填入当前模式的示例数据，
便于快速体验效果。

### 第 3 步：实时预览

右侧画布即时反映所有设置与数据（**预览即最终输出效果**）。
调整左侧任何参数、修改数据、切换颜色条、换颜色，预览都会自动刷新。

### 第 4 步：高级设置（可选）

- **颜色条开关**：勾选 / 取消「显示颜色条」，热力图随附的颜色条即时显示或隐藏；
- **自定义颜色**（仅自定义模式可用）：点击色块可换色，点「添加颜色」「移除最后」
  调整颜色锚点数，点「默认蓝白红」恢复；
- **自定义模式全参数**（仅自定义模式可用，**作图自由度最高**）：
  - 颜色映射（matplotlib 名称或自定义色块）、vmin / vcenter / vmax、数值格式
    （百分比 2 位 / 2~4 位小数 / 原始）、标题；
  - 元素布局：**镧锕三行块（重构）** 或 **展开 8-9 行（经典）**；
  - 图表类型：**热力图** 或 **标注图（文本）**（标注图可复现两种标注样式）；
  - 字体（Arial / Helvetica / DejaVu Sans）、格子边框（无 / 黑色细线）、
    空值格颜色（浅灰 / 白 / 透明）；
  - 输出分辨率 dpi（72~300，PNG 有效；SVG/PDF 为矢量不受 dpi 影响）与
    **图尺寸**（宽×高 英寸，如 `12x6`）——直接决定成图质量与画幅；
- **命名预设**：输入预设名 → 「保存预设」把当前整套设置+数据存下来；
  之后从列表选择 → 「加载」一键恢复，「删除」移除。预设保存在项目 `presets/` 目录。

### 第 5 步：调整界面（按需）

- **布局**：「视图 → 布局」选 左右分栏 / 上下分栏 / **自动调整**。
  自动模式下，窗口宽度低于约 1150px 自动切为上下分栏，宽窗口切回左右分栏；
- **界面缩放**：「视图 → 界面缩放」选 **自动**（字号与控件随窗口宽度缩放
  0.8~1.5 倍）或手动 80% / 100% / 125% / 150%；
- **预览区域大小**：「视图 → 预览区域大小」调节预览区 / 数据区比例
  （40% / 50% / 60%）。

以上选择与窗口尺寸都会自动保存（`~/.periodic-table-tool.json`），下次启动自动恢复。

### 第 6 步：生成图片

1. 选择**输出格式**：SVG（矢量，默认）/ PNG / PDF；
2. 确认**输出目录**（默认项目 `output/` 目录，可点「浏览」更改）；
3. 点 **「生成图片」**：文件自动命名为 `periodic_table_时间戳.svg`，
   同一秒内多次生成自动追加序号（`_2`、`_3`…），**绝不覆盖**已有文件；
4. 生成后可选择直接打开图片查看，或点「打开输出目录」浏览。

## 数据文件格式

每行一个元素，符号与数值之间用**空格 / 逗号 / 等号 / 冒号**分隔，`#` 开头为注释：

```
# 热力图模式（数字）
Ag, 0.0101
Au = 0.0111
Sc 0.0234

# 标注模式（文本，允许任意字符）
Ti: 1b
Zr: 3c1
```

也支持 Python 字典文本 `{'Ag': 0.0101, 'Au': 0.0111}` 和 JSON `{"Ag": 0.0101}`。

## 常见问题（FAQ）

**Q1：提示缺少模块？**
先执行 `pip install -r requirements.txt`（matplotlib、numpy 两个依赖）。

**Q2：预览区显示"预览不可用"？**
当前环境缺少 TkAgg 图形后端（多见于无显示服务器）。不影响正常出图，点「生成图片」
仍可正常保存文件。

**Q3：为什么我的颜色条开关/自定义颜色是灰的？**
自定义颜色仅「自定义 · 热力图」模式可用；其他模式为保证与原脚本输出一致，
颜色固定不可改（但颜色条开关对所有热力图模式都可用）。

**Q4：预设保存在哪里？**
项目根目录 `presets/` 下，每个预设一个 JSON 文件，可手动备份 / 迁移。

**Q5：输出文件会覆盖旧的吗？**
不会。文件名自动带时间戳，同秒冲突时自动追加序号，历史文件全部保留。

**Q6：怎么把界面恢复默认？**
「视图」菜单中：布局选「自动调整」、界面缩放选「自动」、预览区域选 50%；
如需彻底重置，删除 `~/.periodic-table-tool.json` 后重启。
