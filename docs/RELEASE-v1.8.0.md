# v1.8.0

按实际 Excel 数据与 SVG 样图改进绘图编辑。科学模式修正锕系原子序数范围为 89～103，默认使用十进制四舍五入；需要复现原脚本时可选择兼容模式。

- 图形标注默认开启，点击选中并编辑；左拖调整单个标注，固定画幅下左拖颜色条，右键平移预览。拖动有目标框提示，释放后更新图片，可撤销。
- 单元素可分别隐藏数值、隐藏数据着色、排除自动范围，原值保留。显示状态和位置随项目、样式预设保存。
- 预设默认只保存和套用样式，保留当前 Excel 组、数据与输出位置；显式勾选包含数据后才替换数据。
- 新增 PNG/JPG/SVG 样图对照窗口，独立缩放、平移与手动刷新当前预览快照。支持本程序及 Matplotlib 导出的静态 SVG，不自动识别样式。
- 增加毫米画幅、主图区边距、颜色条位置和尺寸输入，以及固定画幅/紧裁切选择。
- 已导入的同指标 Excel 数据组可多选批量导出；修复切组后标注框保留旧值的问题。
- 新增 API v1 本地 JSON 接口，支持能力查询、创建/读取项目、修改前校验、带版本指纹的更新、Excel 导入和三种图片导出。源码和免环境 EXE 均可供 Agent 调用，使用方法及请求示例见 README 与 examples/agent。

源码运行要求 Python 3.10+；Windows EXE 内置 SVG 样图依赖。新字段需用本版编辑，旧版可能丢弃单元素设置。紧裁切改变最终输出尺寸，精确尺寸与颜色条拖动建议使用固定画幅。兼容模式保留历史错误与舍入，以保障旧脚本输出复现。
