# v2.0.0-alpha.1 · Qt 绘图工作台预览版

本版将默认桌面切换为 PySide6 / Qt Widgets，保留独立 PlotSpec 绘图内核和 Agent API。稳定版本仍为 v1.9.0。

## 下载与使用

- Windows 用户下载 `PeriodicTableTool.exe`，双击运行，无需安装 Python。
- 源码包为 `periodic-table-tool-v2.0.0-alpha.1.zip`；安装依赖后运行 `python main.py`。
- 首次使用点击「开始 → 载入示例」，在底部表格编辑数值，点击元素修改标注，通过「文件 → 输出设置」选择目录和格式，再点击「导出图片」。
- `SHA256SUMS.txt` 提供发行附件校验值。

## 主要变化

- Excel 式功能区、Ctrl+K 命令搜索、工作表标签和可停靠面板，统一功能入口。
- 系统 DPI 自适应、矢量图标、随窗口尺寸提高预览分辨率；预览质量与正式导出 DPI 独立。
- 元素标注、色条拖动、属性编辑、配色节点和色条刻度表，继续支持精确参数与高级配置。
- Excel 异步预览、数据组切换、项目保存、撤销恢复、预设和批量导出。
- 修复表格、公式栏与属性面板交错编辑时的数据覆盖；无效输入保留并提示，后台预览不强制提交正在输入的内容。
- 修复失败打开项目时提前清除恢复草稿的问题。
- 隔离 EXE 构建依赖搜索路径，避免外部工具的 ICU DLL 混入 Qt 程序。
- 冻结程序验收覆盖实际预览、PNG/SVG/PDF 导出及 Agent v1/v2 调用。

## 兼容性与限制

旧项目需要显式迁移并另存副本。迁移期保留 `--ui=tk` 作为上一版 schema 2 桌面回退入口。新桌面不依赖原始脚本编号；兼容模块和回归样本仍保留。

本版属于预览发行。自动验收使用 Qt 离屏平台，已生成真实界面截图；可见桌面鼠标流程和多显示器切换仍待人工验收，不以自动测试代替。

完整操作与扩展方式见 [Qt 工作台说明](QT-WORKBENCH.md)；自动化绘图见 [Agent v2](AGENT-V2.md)。
