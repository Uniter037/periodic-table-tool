# 独立桌面工作台（2.0 开发中）

源码默认入口为 `python main.py`。本次不是发行版，现有 v1.9.0 EXE 未更新。

## 日常绘图

1. 导入 TXT/CSV/TSV/JSON 或粘贴元素数据；Excel 通过工作表与矩阵区域向导导入。表格中双击数值单元格编辑，Enter 提交、Escape 取消。
2. 在右侧选择外观预设，或直接编辑图形类型、元素布局、颜色、范围和格式。预设是普通配置，不绑定脚本。默认套用样式时保留数据及 Excel 分组。
3. 点击「自动范围」适配当前数据；比较多张图片时，手动固定统一范围。
4. 标注编辑默认开启。点击预览中的元素，输入新值并应用；拖动标注调整位置。在「显示 / 位置」中设置单元素显示、着色及是否参与自动范围。修改后预览自动更新；旧预览未更新前禁止拖动。
5. 色条可整体隐藏，标签可逐行增加、删除、编辑和隐藏；隐藏行保留数值。可以配置颜色节点、字体、布局、精确几何、背景及边框，完整配置还可通过高级编辑器编辑。画幅输入可切换毫米／英寸，项目统一存储英寸；切换单位不会修改图形尺寸。
6. 「项目 → 输出设置」选择目录、基础名和 SVG/PNG/PDF。导出自动附加时间戳，已有文件不覆盖。预览有分辨率上限，正式导出按设置的画幅和 DPI；SVG/PDF 适合放大排版。

## 项目、数据和恢复

- 保存使用 schema 2；Ctrl+S 保存，Ctrl+O 打开，Ctrl+Z/Y 撤销/重做。
- Excel 数据组各自保留编辑，可切换或选择同一指标的多个组批量导出。当前为矩阵导入，公式读取已保存的结果，不执行公式。
- 旧 schema 1 项目显示迁移提示，确认后转换为未命名工作区。保存需另存副本；旧模式对应配置保留在文档变体中，目前不提供变体切换界面。
- 文件修改冲突会拒绝保存，需重新打开核对，不会静默覆盖其他程序的修改。另存不能直接覆盖尚未加载的陌生项目。
- 2.0 的草稿、预设、偏好和日志与旧版分开。下次启动可恢复未保存草稿；恢复后另存项目。
- 「视图 → 布局与界面缩放」可选择自动/三栏/上下布局和字号控件倍率。分隔条可拖动调整数据区与预览区大小，小窗口使用设置抽屉。
- 「日志与排错」提供日志开关、级别、临时详细记录及诊断包。日志不主动记录用户数值数据。

## 结构与扩展

| 模块 | 职责 |
| --- | --- |
| `main.py` | 冻结进程初始化、Agent/桌面入口分发 |
| `ui/workbench_v2.py` | 桌面布局、交互、后台预览/导出调度 |
| `ui/plot_settings_v2.py` | 控件文本与合法 PlotSpec 的转换；不操作文件与会话 |
| `application/workbench_session.py` | 原子状态变更、历史、项目持久化、Excel 组、预设、草稿 |
| `application/plot_service.py` | 数据/绘图验证及统一渲染入口 |
| `domain/plot_spec.py` | 类型、范围和配置契约 |
| `infrastructure/rendering/` | 颜色、文本、色条与元素布局的实际绘制 |
| `core/jobs.py` | 原生引擎进程隔离、过时请求丢弃和导出暂存 |

新增绘图能力先扩展 PlotSpec 与渲染服务，再接设置面板；不要在界面中加入按旧样式 ID 判断的分支。桌面与 Agent 共享相同配置语义。UI 与会话对象返回的快照不得直接修改，使用 session.patch 提交验证后的事务。

迁移期旧桌面在 `ui/legacy_workbench.py`，旧回归测试显式导入它；新默认启动路径不得加载 `core.styles/options/scientific/ptable`。旧代码及原始参考测试仍保留，尚未完成最终删除、安装包验收和新版本发布。入口隔离不等于历史文件已经清除。
