文档版本：1.0；日期：2026-11-05；代码基线：v1.6.0。状态：设计交付，尚未实现。产品发行版本由里程碑验收后决定，不因本文件创建而修改。

## 目标与阅读顺序

建设离线、免部署、可承担实际科研绘图任务的 Windows 桌面工具。用户可以直接导入 Excel，保留原始数据和文字精度，选择实验条件、数值和类别绑定，交互编辑并输出高质量周期表。保持14种样式、高自由度及13种历史脚本兼容能力。

1. [产品规格](01-product.md)：用户流程、完整能力和边界行为。
2. [架构与数据契约](02-architecture.md)：模块责任、数据结构、服务接口、并发和迁移。

## 核心决策

- 采用模块化单体，继续使用 Tkinter/ttk、Matplotlib Agg、NumPy、Pillow；本轮不更换 GUI 框架，不引入服务器或数据库。
- Excel 读取适配器拟采用 openpyxl，仅读取 `.xlsx`，不依赖电脑安装 Excel。实施时核验依赖、许可证与打包兼容性并锁定构建版本。
- 单一项目状态、单向更新；UI 不拥有业务规则，渲染不读取界面控件。
- 标准化数据与显示文字分离；色标范围、配色中心、刻度文字分离；UI 缩放与输出尺寸分离。
- 通过适配层渐进替换，保留原兼容绘图入口；禁止一边抽取模块一边无记录改变历史绘图语义。
- 提供内置注册表扩展读取器、样式和输出格式；本轮不开放执行第三方脚本的插件系统。
- 不以新增选项数量衡量完成度，以实际文件从导入到成图的端到端成功率衡量。

## 已核对的基线与差距

现有 `main.py` 同时负责窗口、数据导入、项目、预设、色标和任务编排；`core/styles.py` 已有 STYLES 与 render_table；`core/jobs.py` 已有独立 spawn 绘图进程；`core/document.py` 使用 schema=1 JSON 项目和原子写入；`ui/preview.py` 已支持预览操作。当前依赖未列出 Excel 读取器，现有说明面向文本、CSV、TSV、JSON和两列粘贴。

因此新工作重点是：Excel 数据模型、多数据组项目、数据关联、导入映射、可扩展绑定和状态分层，而不是重复实现已有颜色条、缩放、撤销或进程能力。已有实现仍必须重新通过新契约的回归验收。

## 交付边界

本次交付为设计文档和任务拆分，不代表功能已经实现，也不自动授权发布。实际开发按任务书分阶段实施；每个里程碑必须可启动、可绘图、可回退。真实 Excel 是本地验收输入，不默认加入公共仓库或发行包，公共测试使用等结构合成数据。
