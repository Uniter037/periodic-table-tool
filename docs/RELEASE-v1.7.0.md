# v1.7.0

支持直接导入 XLSX 横向/纵向元素矩阵，并在项目中保存和切换多组数据。增加日志总开关、详细级别、临时调试和本次诊断包导出。

- 工作表和元素/条件/数值区域可选择，异常输入保留原项目。
- 各数据组编辑独立保留，支持保存重开与撤销重做。
- XLSX读取无需安装Excel或额外Excel运行环境；公式使用工作簿已保存结果。
- 继续提供原脚本兼容模式和PNG/SVG/PDF导出。

下载 PeriodicTableTool.exe 可直接运行；Windows ZIP同时包含使用说明；另附源码ZIP与SHA256校验和。

当前限制：XLSX界面支持矩阵导入；分类分组导入、自动源更新和Excel多组批量导出界面尚未提供。日志包覆盖本次运行。新项目含数据组扩展字段，建议使用本版继续编辑，旧版不会保留扩展字段。
